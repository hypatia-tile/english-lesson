# Body templates

Headings are a guide, not a contract: drop a section that has nothing to say.
Explanations in Japanese; headwords and examples in English.

## word

```markdown
# <headword>

<品詞> /<IPA>/

## 意味・ニュアンス
## 例文
## 類義語・関連語
```

## phrase

```markdown
# <phrase>

## 意味・ニュアンス
## 例文
## 使う場面・注意点
```

## grammar

```markdown
# <topic in English>

## ルール
## 例文
## よくある間違い
```

## correction

```markdown
# Correction

## 元の文
> <user's sentence>

## 修正案
> <corrected sentence>

## 解説
## 別の言い方
```

## compare

```markdown
# <a> vs <b>

## 違いの要点
| | <a> | <b> |
|---|---|---|

## 例文
## 迷ったときの判断基準
```
